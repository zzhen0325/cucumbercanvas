# E2E Test Configuration

このファイルはE2Eテストコマンドで使用するプロジェクト固有の設定を定義します。

## プロジェクト設定

| 設定項目 | 値 | 説明 |
|---------|-----|------|
| 開発サーバーURL | `playwright.config.ts` の `baseURL` を参照 | テスト対象のベースURL |
| 開発サーバー起動コマンド | `npm run dev` | 開発サーバー起動コマンド |
| ビルド＆起動コマンド | `npm run build && npm run start` | プロダクションビルド＆サーバー起動 |
| テストディレクトリ | `playwright-tests/` | Playwrightテストコードの格納先 |
| ドキュメントディレクトリ | `docs/e2e/` | E2Eテストドキュメントの格納先 |
| コーディング標準 | `docs/coding-standard/playwright.md` | Playwrightコーディングガイドライン |
| 認証が必要 | TBD（`/e2e:init`で判定） | 認証要否は`/e2e:init`実行時に自動判定 |

> **Note**: `/e2e:init` を実行すると、プロジェクト分析に基づいて認証設定が自動的に更新されます。

## Kiro連携設定（オプション）

| 設定項目 | 値 | 説明 |
|---------|-----|------|
| 製品要件 | `.kiro/steering/product.md` | 製品仕様と要件（存在する場合） |
| 技術仕様 | `.kiro/steering/tech.md` | アーキテクチャと技術スタック（存在する場合） |

## デフォルト値

設定ファイルが存在しない場合、以下のデフォルト値が使用されます：

| 設定項目 | デフォルト値 |
|---------|-------------|
| 開発サーバーURL | http://localhost:3000 |
| テストディレクトリ | playwright-tests/ |
| ドキュメントディレクトリ | docs/e2e/ |

## カスタマイズ方法

プロジェクトの要件に応じて、上記の設定値を変更してください。

### 例: ポート番号を変更する場合

1. `playwright.config.ts` の `baseURL` を変更
2. この設定ファイルの変更は不要（自動的に反映）

### 例: テストディレクトリを変更する場合

「プロジェクト設定」セクションの「テストディレクトリ」を変更：

```markdown
| テストディレクトリ | `e2e/` | Playwrightテストコードの格納先 |
```
